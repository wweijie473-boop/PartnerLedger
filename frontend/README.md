# PartnerLedger Vue 前端

使用 Vue 3、Vite 和 Element Plus。在 PowerShell 中运行以下命令，然后打开终端显示的 `Local` 地址。

```powershell
Set-Location F:\PartnerLedger\frontend
npm ci
npm run dev
```

## 入口与体验

打开 `/` 选择代理商、软件厂商或企业客户。三个独立入口为 `/login/dealer`、`/login/vendor`、`/login/customer`。客户正式认证尚未开放，其入口不会收集密码。

无需启动后端即可访问 `/experience/dealer`、`/experience/vendor`、`/experience/customer`。每个角色有自己的待办和项目台账。打开详情后点击「切换身份」，下一个角色会进入同一项目；只有询价提交后，厂商才可看到项目。演示仅在同源浏览器之间共享本机样例，适合在同一浏览器的三个标签分别扮演三方。只使用虚构数据；「重置演示」会同时恢复三端样例。

从零体验：客户提交 ERP 采购需求 → 代理商核对字段并询价 → 厂商填写授权与实施明细 → 代理商独立编制对客报价 → 客户确认 → 代理商单独下单 → 厂商供货 → 代理商提交实施验收 → 客户确认或退回整改。也可从初始台账直接打开已经到达相应阶段的记录。

## 后端工作台

商机拾遗演示位于 `/experience/dealer?view=opportunities`。从代理商项目详情也可进入「记录走访与补充需求」。试填「ERP 已定，客户还需要 IDE 接口」：先核对提取出的副需求，再选择服务类型与系统；不确定时可以留空。查看匹配依据、登记引荐、到期回访和合作结果。新增伙伴后可直接回访尚未承接的历史商机。演示数据仅供体验，介绍费是人工台账，不执行收款。[后端交班与验收脚本](../docs/opportunity-handoff.md)。

按 [Go 后端启动说明](../backend/README.md) 配置 MySQL、Redis，执行迁移并开通厂商或代理商账号，再启动 Go 服务。从相应登录入口登录，工作台以服务端返回的组织为准。Vite 默认把 `/api` 转发到 `http://127.0.0.1:8080`。Go 改用其他地址时，在运行 `npm run dev` 前设置 `PARTNERLEDGER_API_TARGET`。部署时将 `/api/*` 转发到 Go，本地静态资源直接提供，前端页面路径（含登录及演示深链接）回退到 `index.html`。

- 厂家可新增、修改产品和发布状态；经销商可分页查看已发布的产品及详情。
- 代理商可提交脱敏需求给后端解析，或手工整理。员工人数和授权用户数分开显示，未知授权数可留空。确认结果保留在当前页面。真实模型调用需要在后端配置 `DEEPSEEK_API_KEY`；演示端的辅助整理仅使用本地规则。
- 「账号与组织」显示后端返回的组织和用户，可注销当前会话。在同一浏览器标签刷新页面时，会重新核验会话。

## 双角色演示

旧版原型保留在 `/demo`，独立于三个新工作台。右上角可切换厂家与经销商，底部「重置数据」只重置旧原型。以下是旧版演示流程。

从工作台底部选择「组件库」或打开 `/ui`，可查看企业级配色、图标、卡片和交互状态。新增页面时，先参考 [UI 组件使用说明](src/ui/README.md)。

1. 经销商填写需求，保存草稿或提交询价。授权用户数待确认时可留空。厂家可要求补充资料，经销商补充后重新提交。
2. 厂家录入金额、明细和有效期后发送报价。经销商可请求修改，厂家发出新版后仍可查阅旧版。
3. 经销商确认当前有效报价，再单独生成订单。在「订单与交付」查看订单和交付节点。
4. 厂家依次更新授权、部署、迁移和交接，经销商切回后可查看进度。用页面底部的「界面状态」预览加载、空数据、无权限和失败重试。

运行 `npm test` 验证三端业务规则与接口适配，`npm run build` 验证生产构建。后续接入见 [项目接口契约](../docs/channel-contract.md)，其中列出了动作、可见字段、版本冲突及幂等规则。

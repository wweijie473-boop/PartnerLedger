# PartnerLedger Vue 前端

使用 Vue 3、Vite 和 Element Plus。在 PowerShell 中运行以下命令，然后打开终端显示的 `Local` 地址。

```powershell
Set-Location F:\PartnerLedger\frontend
npm ci
npm run dev
```

## 后端工作台

默认入口 `/` 使用真实账号。按 [Go 后端启动说明](../backend/README.md) 配置 MySQL、Redis，执行迁移并开通厂家或经销商账号，再启动 Go 服务。Vite 默认把 `/api` 转发到 `http://127.0.0.1:8080`。Go 改用其他地址时，在运行 `npm run dev` 前设置 `PARTNERLEDGER_API_TARGET`。部署时，用同源反向代理将 `/api` 发给 Go，并将 `/`、`/demo` 和 `/ui` 交给前端。

- 厂家可新增、修改产品和发布状态；经销商可分页查看已发布的产品及详情。
- 经销商可提交脱敏需求给后端解析，查看并编辑返回字段。员工人数和授权用户数分开显示，未知授权数可留空。确认结果保留在当前页面。真实模型调用需要在后端配置 `DEEPSEEK_API_KEY`。
- 「账号与组织」显示后端返回的组织和用户，可注销当前会话。在同一浏览器标签刷新页面时，会重新核验会话。

## 双角色演示

从登录页选择「打开模拟演示」或访问 `/demo`。右上角可切换厂家与经销商。询价、报价、订单和交付仍使用这一原型，记录保存在当前浏览器，底部的「重置数据」可以恢复示例。以下流程可从任一产品详情或「新建需求」开始。

从工作台底部选择「组件库」或打开 `/ui`，可查看企业级配色、图标、卡片和交互状态。新增页面时，先参考 [UI 组件使用说明](src/ui/README.md)。

1. 经销商填写需求，保存草稿或提交询价。授权用户数待确认时可留空。厂家可要求补充资料，经销商补充后重新提交。
2. 厂家录入金额、明细和有效期后发送报价。经销商可请求修改，厂家发出新版后仍可查阅旧版。
3. 经销商确认当前有效报价，再单独生成订单。在「订单与交付」查看订单和交付节点。
4. 厂家依次更新授权、部署、迁移和交接，经销商切回后可查看进度。用页面底部的「界面状态」预览加载、空数据、无权限和失败重试。

演示入口的产品、价格和组织均为虚构数据。身份、订单、金额和状态由浏览器模拟。真实的授权计价、补资料及撤回规则、报价有效期和交付节点，应在调研及契约确认后再定。`npm run build` 可验证生产构建。

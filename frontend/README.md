# PL-004 双角色原型

使用 Vue 3、Vite 和 Element Plus。在 PowerShell 中运行以下命令，然后打开终端显示的 `Local` 地址。

```powershell
Set-Location F:\PartnerLedger\frontend
npm ci
npm run dev
```

第一次打开会进入经销商工作台。右上角可以切换到厂家，或退出后从演示登录页重新选择身份。记录保存在当前浏览器，底部的「重置数据」可以恢复示例。以下流程可从任一产品详情或「新建需求」开始。

从工作台底部选择「组件库」或打开 `/ui`，可查看企业级配色、图标、卡片和交互状态。新增页面时，先参考 [UI 组件使用说明](src/ui/README.md)。

1. 经销商填写需求，保存草稿或提交询价。授权用户数待确认时可留空。厂家可要求补充资料，经销商补充后重新提交。
2. 厂家录入金额、明细和有效期后发送报价。经销商可请求修改，厂家发出新版后仍可查阅旧版。
3. 经销商确认当前有效报价，再单独生成订单。在「订单与交付」查看订单和交付节点。
4. 厂家依次更新授权、部署、迁移和交接，经销商切回后可查看进度。用页面底部的「界面状态」预览加载、空数据、无权限和失败重试。

所有产品、价格和组织均为虚构演示数据。身份选择和操作权限由前端模拟，订单、金额和状态也保存在浏览器。真实的授权计价、补资料及撤回规则、报价有效期、组织隔离和交付节点，应在调研及 `PL-003` 契约确认后再定。`npm run build` 可验证生产构建。

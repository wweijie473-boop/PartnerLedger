# 蓝色企业界面改版交接

交付日期：2026-11-19。对应 [执行计划](interface-redesign-plan.md)。本次由前端侧完成，后端伙伴继续按现有业务契约推进。

## 已交付

- 门户：白色导航、深蓝首屏、三种登录入口、可切换的协作案例、商机拾遗介绍。首屏保留远端最新的原创 Canvas 抽象动效，加入浅色衬底以适配深蓝首屏；三方业务关系由下方案例说明。动效尊重减少动态效果设置，无需下载图片或微软素材。
- 统一组件：蓝色操作、浅蓝灰底、白色卡片、语义状态；字体、行高、按钮、标签、字段、统计卡、对话框和焦点样式同步调整。/ui 展示配色、按钮状态、图标和项目进度组件。
- 三端共用外壳：232px 导航、56px 顶栏、面包屑和组织信息；860px 以下使用导航抽屉，支持 Escape、Tab 焦点约束、背景不可操作和关闭后焦点返回。
- 正式工作总览：调用现有项目仓库，显示可见项目数、待我处理数、协作方处理数和可直接打开的项目待办。没有接口数据时显示空状态或读取失败，不使用演示记录填充。
- 三端项目：状态标签、当前角色可见的协作进度、下一步操作、需求资料、两类报价、履约信息和时间线统一阅读层级。演示与正式工作台继续分离。
- 商机与拜访：台账、任务、伙伴依据、联系前核对、引荐和费用记录、手机草稿、恢复提交界面统一配色与字号。
- 产品、AI 和旧原型：沿用统一组件与布局；手工需求路径和真实产品权限继续保留。
- 表格：页头、表格列表、工具栏、公式栏、选区、保存提示、设置弹窗与查找替换面板接入主题变量；保留虚拟行高、坐标计算和保存队列。

## 前端接续约定

主题入口是 frontend/src/ui/theme.css。正文 14px，关键状态 14px，辅助信息 12px；普通控件 40px，紧凑按钮 32px，手机主要操作 44px。门户标题为手机 32px、中屏 44px、大屏 56px。正文链接使用 --ui-link，主操作背景使用 --ui-accent，两者不要混用。

UiProjectProgress 已从组件库导出，参数为 role（dealer/vendor/customer）、stage 和 label。只传当前账号可见的项目投影；客户的 processing 不推断上游内部步骤。未知状态隐藏进度，业务按钮仍由返回的 actions 决定。statusTone.js 负责状态标签的语义颜色。

正式总览通过 LiveProjects 的 overview 模式复用现有列表 API，待办使用服务端 isTodo 和 nextStep，点击后进入同一项目详情。统计卡为只读汇总，避免暗示未实现的筛选操作。手机收紧统计卡，优先保留待办空间。

已快进同步远端 7513e68 与 d2b9b8f，保留 PortalArtwork.vue 的抽象动效实现，合并门户布局及响应式样式。

本次没有修改接口路径、请求键、版本控制、权限投影或数据库迁移，也未增加组件框架依赖。后端继续使用现有分支能力即可。正式项目仍只开放建项、询价、撤回、补资料及能力缺口；报价、订单、供货、实施与验收的完整闭环仍在 /experience 演示。

产品明细若只返回产品编号，前端保留编号兜底。后续项目投影可增加当前角色有权查看的 productName，减少重新打开记录时显示纯编号的情况；本轮不依赖这个新增字段。

## 本轮验证

写入检查使用独立的本机 MySQL 和临时 Redis、虚构组织与账号；未向团队共用数据库写入验收数据。临时服务、测试账号及截图留在本机，不提交真实连接信息。

- npm test：27 项通过，涵盖三端流程、报价版本与过期、重复下单、角色投影、商机、草稿隔离、写入重放、版本冲突、表格公式和保存队列。
- npm run build：生产构建通过。
- 浏览器正式链路：客户建项 → 代理商询价 → 厂商要求补资料 → 代理商向客户补问 → 客户答复 → 代理商回传 → 厂商标记附加能力缺口。刷新后记录存在。厂商页面不含客户原始需求及内部预算；客户页面不含厂商补问、能力缺口和上游摘要。另一代理商访问同一编号显示不可访问。
- 浏览器拜访：保存、核对、确认生成正式商机、打开关联记录通过；模拟服务端保存后响应丢失，刷新保留原请求，重放后仍只有一条草稿。
- 浏览器 AI：未配置模型的测试后端返回失败提示，随后可进入手工填写。
- 浏览器表格：新建、粘贴、公式计算、查找替换预览及提交、撤销重做、自动保存通过；另一写入产生新版本后，可在最新版重放本标签页改动；组织内只读账号显示只读，编辑和替换不可用。
- 375、540、860、1440、1920px 检查门户、三端演示、组件页及旧原型：无页面横向溢出，宽表格在自己的滚动区内。375px 正式拜访检查通过。手机导航 Tab 循环、Escape 关闭、返回触发按钮及背景恢复可操作通过。

以上单元测试覆盖的商业流程不代表正式报价接口已上线；正式与演示能力以上述范围为准。浏览器截图在本机保留，包含门户、三个工作台/角色页面、项目详情、伙伴匹配、手机拜访和表格查找替换。

## 拉取后查看

在 frontend 运行 npm run dev -- --host 127.0.0.1，打开终端给出的地址。首页进入三种角色；免账号查看可用 /experience/dealer、/experience/vendor、/experience/customer。/ui 是组件样板，/tables 需要真实后端及表格迁移。正式接口代理配置保持原有 PARTNERLEDGER_API_TARGET 约定。

后端后续接入报价与履约时，沿用现有数据访问层和两类报价的权限边界。若增加新业务状态，同时更新语义标签和角色进度映射；不要让客户进度显示渠道成本、内部折扣或毛利。
